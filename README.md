# Resume Screener AI

An AI-based resume screening system that analyzes resumes and compares them with job descriptions using NLP techniques.

## 🚀 Features
- Extracts text from PDF resumes
- Matches skills with job requirements
- Uses TF-IDF and cosine similarity for scoring

## 🛠️ Technologies Used
- Python
- PyPDF2
- Scikit-learn

## ▶️ How to Run
1. Install dependencies:
   pip install PyPDF2 scikit-learn

2. Place your resume as `resume.pdf`

3. Run:
   python main.py

## 📊 Output
- Similarity Score between resume and job description
